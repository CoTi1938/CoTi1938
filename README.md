## CUDA on eight NVIDIA GPUs

I shipped a 20-PR CUDA stack for Qwen3.6-35B-A3B INT4, benchmarked and tuned across eight NVIDIA GPUs. Each card ran 16 workloads, including an eight-turn chat. **Prompt processing was faster in all 128 GPU-workload comparisons**, and steady generation was faster in 127. Across three runs per workload on each GPU, the optimized code produced the same FP32 logits as the baseline, bit for bit. [Timings and correctness by GPU](https://github.com/CoTi1938/colibri/tree/vetrina#results-by-gpu) · [The 20 PRs in order](https://github.com/CoTi1938/colibri/tree/vetrina#cuda-pull-requests-in-order)

On the **RTX 4090**, colibri processed a 16,384-token prompt at **12,311 tokens/s**, up from **6,295** (steady generation 162.51 → 180.89 tokens/s); on the **RTX 5090**, the same prompt rose from **8,364** to **16,518 tokens/s** (steady generation 243.65 → 253.42 tokens/s). In a separate test on an RTX PRO 4000 Blackwell SFF Edition, the maintainer saw a 9,870-token prompt go from 3.3 to 2.4 seconds with the same generated text. ## Qwen3.6 on Apple Silicon

On a fanless **MacBook Air M1 with 8 GB of unified memory**, the Qwen3.6 Metal graph ran the 35B model and processed a 512-token prompt at **111 tokens/s**, up from **3.13 tokens/s on CPU**.
